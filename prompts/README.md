hackathon (Guía § Entregables).

Convención (Guía § Reglas de trabajo): cada persona guarda sus prompts en
`/prompts/<rol>.md` **mientras trabaja, no al final**:

| Archivo | Rol |
| --- | --- |
| `rol-1.md` | Líder técnico e integración Open Payments |
| `rol-2.md` | Backend y datos |
| `rol-3.md` | Frontend del punto y del beneficiario |
| `rol-4.md` | Frontend de la entidad y diseño |
| `rol-5.md` | Producto, pitch y calidad |
